# Inventario de interacción de referencia

REA se mantiene configurado solo para investigación. Las implementaciones de Superemporio son originales.

| Patrón observado | Adaptación Superemporio |
| --- | --- |
| Header fijo y acceso rápido a categorías | Navegación compacta, con acciones de cuenta y carrito accesibles. |
| Carrito lateral | Drawer en escritorio y panel de ancho completo en móvil. |
| Cantidad editable en carrito | Stepper de 44 px y actualización optimista. |
| Variantes de producto | Packs/unidades con SKU, precio y stock independiente. |
| Promociones visuales | Campaigns administrables en banner, aviso y modal; sin copiar creatividad ajena. |
| Checkout directo | Costos transparentes, invitado permitido y alternativa de WhatsApp. |

Antes de una iteración visual se deberá capturar una nueva sesión de REA con estados de móvil, carrito, búsqueda y checkout para revisar el comportamiento, no para extraer assets ni código.
